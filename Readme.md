# 🗺️ Diplomado en Administración de Sistemas de Información Geográfica (SIG)

**Material académico, ejercicios y recursos de apoyo para la administración de plataformas SIG con tecnología Esri.**

Este repositorio reúne recursos utilizados durante el **Diplomado en Administración de Sistemas de Información Geográfica (SIG)**. Su propósito es facilitar el acceso al material de estudio, apoyar las actividades prácticas y servir como referencia para comprender los conceptos de administración, configuración y operación de plataformas geoespaciales.

> **Nota:** Los contenidos y archivos pueden actualizarse a medida que avanza el diplomado. La disponibilidad de software, licencias y entornos de práctica dependerá de las indicaciones de cada sesión.

## 🎯 Objetivos de aprendizaje

- Comprender los componentes de una plataforma SIG y su función dentro de una arquitectura empresarial.
- Familiarizarse con los fundamentos de administración de soluciones basadas en tecnología Esri.
- Fortalecer las habilidades de configuración, operación y mantenimiento de entornos geoespaciales.
- Aplicar buenas prácticas de seguridad, disponibilidad y gestión de recursos SIG.
- Desarrollar criterios para diagnosticar problemas habituales de administración y operación.

## 🛠️ Tecnologías y temas de referencia

A lo largo de la formación pueden abordarse conceptos relacionados con:

- **ArcGIS Enterprise:** componentes, arquitectura y administración de plataformas SIG empresariales.
- **Portal for ArcGIS:** usuarios, grupos, contenido y mecanismos de acceso.
- **ArcGIS Server:** publicación, organización y operación de servicios geográficos.
- **ArcGIS Data Store y geodatabases:** fundamentos de almacenamiento y administración de datos geoespaciales.
- **Infraestructura y redes:** conectividad, certificados, recursos de cómputo y dependencias.
- **Seguridad y continuidad:** buenas prácticas de operación, monitoreo, respaldo y recuperación.

*Esta sección describe áreas temáticas de referencia; no constituye un temario oficial ni implica que todas estén cubiertas en los archivos actualmente publicados.*

## 🚀 Cómo utilizar este repositorio

**Opción 1: Consultar en GitHub**

Abre las carpetas de los módulos directamente desde la [página principal del repositorio](https://github.com/cporras1409/DiplomadoAdminSIG).

**Opción 2: Descargar el material**

En GitHub, selecciona **Code → Download ZIP** para obtener una copia de los archivos publicados.

**Opción 3: Clonar con Git**

```bash
git clone https://github.com/cporras1409/DiplomadoAdminSIG.git
cd DiplomadoAdminSIG
```

Para descargar actualizaciones posteriormente:

```bash
git pull origin main
```

## ✅ Recomendaciones para las prácticas

1. Revisa las instrucciones y los requisitos específicos de cada módulo antes de comenzar.
2. Utiliza entornos de laboratorio o pruebas para las actividades de administración.
3. Documenta los cambios de configuración y conserva copias de seguridad cuando corresponda.
4. No publiques contraseñas, tokens, certificados privados ni datos sensibles en el repositorio.
5. Verifica la compatibilidad de versiones y los requisitos de licenciamiento del software utilizado.
